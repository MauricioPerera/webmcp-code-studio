# Glosario de Términos

- **KDD (Knowledge-Driven Development):** Metodología creada por Mauricio Perera que estructura el conocimiento de software en un grafo de nodos navegables y contratos deterministas.
- **OKF (Open Knowledge Format):** Formato estándar de especificación de conocimiento en Markdown con Frontmatter YAML.
- **CCDD (Contract-Driven Development):** Enfoque de desarrollo basado en contratos de tareas con oráculos congelados.
- **WebMCP:** Especificación W3C para habilitar comunicación entre agentes de IA y aplicaciones web a través de herramientas.
- **fastwebmcp:** Biblioteca creada por Mauricio Perera para ergonomía y tipado seguro de WebMCP en JavaScript/TypeScript.
- **VFS (Virtual File System):** Capa de abstracción de sistema de archivos alojada en el navegador del usuario.
- **SPA (Single-Page Application):** Aplicación web que carga un único documento y actualiza dinámicamente la interfaz.
